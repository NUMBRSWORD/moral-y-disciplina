Descargar la aplicación

Instalación directa en Android (sin tienda). Versión 1.3.

Descargar Faltos 1.3 (Android)

Requiere Android 7 o superior. Al ser una instalación directa, el teléfono pedirá permiso para instalar aplicaciones de esta fuente: es normal.

Cómo instalarla

  1. Toque el botón de descarga desde el teléfono.
  2. Abra el archivo descargado.
  3. Si aparece el aviso «Por seguridad, su teléfono no permite instalar apps de esta fuente», toque Ajustes y active el permiso para el navegador.
  4. Vuelva a abrir el archivo e instale.

Descargarla no da acceso

Cualquiera puede instalar la aplicación, pero para ver información hace falta iniciar sesión con Google, que un administrador apruebe la cuenta, firmar las políticas y activar el Token Digital. Sin eso, la aplicación no muestra ningún dato.
